# Short description 
This is a number guessing game. The program selects a secret number between 1 and 1,000. The user guesses numbers until they find the secret number. The number of guesses is displayed at the end.

# Input accepted
The user may enter integers until they guess the secret number.

# Output produced
The program tells you if you're too high or too low to help you narrow down what the secret number is.

# Basic instructions
- Run the program
- Enter an integer
- Keep entering integers until you find the secret number
